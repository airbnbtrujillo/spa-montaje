Spot Spa — propuesta de montaje

Cómo se usa
  1. El programa agrupó las tomas repetidas (mismo plano grabado varias veces) y propuso un orden según tu historia: llegada → ambiente → espejo → pasadizo → sube a la camilla → piedras → vapor → mascarilla → cremas → cierre.
  2. Revisa cada etapa. Marca «En el spot» los planos que quieres, cambia la toma si otra salió mejor, ajusta desde qué segundo y cuántos beats dura, o muévelo de etapa/orden.
  3. Pulsa Descargar decisiones y ejecuta python spa_aplicar.py "ruta\decisiones_spot_spa.json": genera salida\borrador.mp4 y salida\spot.xml (para Premiere).
  4. Tus cambios se guardan solos en este navegador. «Restablecer propuesta» vuelve a la versión automática.

Cómo quedaría (borrador)

Video armado con la propuesta inicial, con los cortes sobre los beats de la música (Wake-Up-MBB-MUSICA-SIN-COPYRIGHT). Está hecho con los proxies de baja resolución, solo para ver el ritmo y el orden. Si cambias algo aquí, descarga las decisiones y regenéralo con spa_aplicar.py.
